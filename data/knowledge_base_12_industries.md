# 费曼星 AI平台 — 知识库完整交付包（终版）

> 版本：V2.0 终版 | 2026-08-05  
> 状态：可直接导入 Dify 使用，无需再审批  
> 覆盖行业：教培 / 电商 / 医美 / 餐饮 / 律所 / 自媒体  
> 包含：默认知识库 + 固定提示词 + 质量标准 + 经验转化全流程

---

## 使用说明（先看这个）

1. **默认知识库**：每个行业一个独立文件夹结构，直接复制对应 Markdown 内容到 Dify 知识库文档即可。
2. **提示词模板**：复制到对应 Dify 应用的 System Prompt。
3. **经验转化**：用户上传资料后，用「经验转化提示词」自动生成结构化知识。
4. **质量红线**：所有高风险行业（医美、律所）必须启用「高风险兜底提示词」。
5. **强制要求**：所有回答必须标注引用来源；知识库无内容时明确说「暂无，建议人工确认」。

### 02_课程体系与价格.md

```markdown
# 课程体系与价格

## 课程分层
1. 体验/测评课：低门槛，用于转化
2. 系统班：主推完整体系
3. 冲刺/提升班：针对阶段性目标
4. 一对一或小班：高客单定制

## 价格话术原则
- 先讲包含内容与价值，再报价格
- 价格必须与「课时 + 教材 + 答疑 + 测试」绑定说明

## 标准回复框架
「这个课程包含【课时数】节课 + 配套教材 + 课后答疑 + 阶段性测试，目前活动价【价格】。建议先预约免费试听，感受后再决定。」

## 禁止事项
- 不得承诺「包过」「保证提多少分」
- 不得恶意贬低其他机构
```

### 03_常见问题FAQ.md

```markdown
# 教培高频FAQ

Q：孩子基础差能跟上吗？
A：我们有入学测评，会根据实际水平分班或调整进度。基础薄弱的学员会先补核心知识点，再进入系统学习。很多学员入学时基础一般，通过正确方法后来进步明显。

Q：一周上几次？会不会影响学校功课？
A：常规班每周【X】次，单次【X】小时，时间尽量与学校课程错开。我们强调高效学习，课堂消化为主，作业量可控。

Q：老师会经常换吗？
A：主讲老师相对固定。如遇特殊情况，会提前通知并做好交接，保证连续性。

Q：中途可以退费吗？
A：具体以合同为准。一般未开课可按规则退费，已开课按实际消耗结算。建议先试听再报名，降低风险。

Q：线上和线下效果差很多吗？
A：我们提供【线上/线下/混合】选择。线上同样有互动、答疑和作业批改，很多家长反馈孩子专注度不亚于线下。

Q：怎么证明有效果？
A：我们有阶段性测试和学情报告。您可以先看脱敏案例，或直接让孩子试听一节，亲自感受。
```

### 04_异议处理话术.md

```markdown
# 异议处理话术

## 觉得贵
「理解您对价格的关注。这个价格已包含课时、教材、答疑和测试，平均每节课【X元】。很多家长反馈，与其报多个效果一般的班，不如集中资源把一个班上透。可以先试听再决定。」

## 再考虑考虑
「完全理解，这是重要决定。建议先预约一次免费试听或测评，让孩子体验，您也看看教学方式和反馈机制。试听不收费、不强制。」

## 其他机构更便宜
「不同机构侧重点不同。我们更看重教学闭环、师资稳定和效果跟踪。您最看重价格，还是最终孩子能真正提升？我们可以按您的需求匹配最合适班型。」

## 孩子没时间/太累
「现在学生确实忙。课程会尽量避开学校高峰，单次时长也控制在可接受范围。真正有效的是短时高效，而不是堆时间。可以先试一次看实际感受。」

## 不相信效果
「效果需要验证。我们不靠口头承诺，而是靠阶段性测试和学情反馈。可以从体验课或短期班开始，看到变化再决定是否继续。」
```

```markdown
「可以先报短期班或体验包，完整体验后再决定是否升系统班，风险最低。」

结束语：
「我把大纲和预约链接发您。有问题随时找我，不用有压力。」
```

## 三、医美咨询知识库（高风险，强制兜底）

### 01_项目介绍框架.md

```markdown
# 医美项目介绍框架

## 回答原则（最高优先级）
- 只做一般性介绍与风险提示
- 绝不给出具体诊断、方案推荐或效果承诺
- 必须引导到线下面诊或人工咨询
- 所有回答末尾加：「以上内容仅供参考，不构成医疗建议，具体需由持牌医生面诊后确定。」

## 标准结构
1. 项目定义（是什么）
2. 常见适用情况（一般性描述）
3. 可能的风险与注意事项
4. 建议：预约正规机构面诊
```

### 02_风险与合规.md

```markdown
# 医美合规红线（必须遵守）

1. 禁止任何效果承诺（「一定变好看」「无风险」等）。
2. 禁止给出具体注射剂量、手术方案、恢复时间保证。
3. 禁止贬低其他机构或医生。
4. 涉及价格只说明「需面诊后确定」，不报具体低价诱导。
5. 发现用户描述疑似医疗问题，立即引导就医或专业咨询。
6. AI只做信息助手，不做医疗决策。
```

### 03_常见咨询话术.md

```markdown
# 医美常见咨询应对

用户问效果：
「每个人基础和体质不同，效果因人而异。建议您到正规医疗机构面诊，由医生根据您的情况评估是否适合以及预期效果。」

用户问价格：
「价格会因项目、用量、机构资质有所不同，需要面诊后才能准确报价。建议您选择有资质的正规机构。」

用户问风险：
「任何医美项目都存在一定风险，包括但不限于感染、效果不理想、恢复期不适等。选择正规机构和有经验的医生是降低风险的关键。」

用户要求推荐方案：
「我无法根据线上描述给出具体方案。请您预约线下专业面诊，医生会结合检查结果给您专业建议。」
```

## 五、律所/法律咨询知识库（高风险）

### 01_咨询边界.md

```markdown
# 法律咨询边界（最高优先级）

AI只能做：
- 一般性法律知识介绍
- 流程说明（如起诉大致步骤）
- 引导用户咨询执业律师

AI绝对不能做：
- 给出具体案件胜诉判断
- 提供可直接执行的诉讼策略
- 代替律师出具法律意见
- 承诺结果

所有回答末尾必须加：
「以上内容为一般性法律信息，不构成法律意见。具体案件请咨询执业律师。」
```

### 02_常见问题框架.md

```markdown
# 法律常见咨询框架

合同纠纷：
「合同纠纷一般可通过协商、调解、仲裁或诉讼解决。具体选择需看合同约定和案件情况。建议您带合同原件咨询专业律师评估。」

劳动争议：
「劳动争议通常先走调解或仲裁程序。建议保留工资流水、劳动合同、考勤等证据，并尽快咨询律师了解时效。」

婚姻家事：
「涉及财产分割、子女抚养等问题，建议双方先协商。协商不成可起诉。具体方案需结合实际情况由律师分析。」
```

### 03_风险红线.md

```markdown
# 律所场景红线

1. 不预测判决结果。
2. 不指导如何「规避法律」。
3. 不接受委托代理（AI无此资格）。
4. 发现紧急情况（家暴、人身安全等）引导报警或寻求即时帮助。
5. 所有回答保持中立、谨慎。
```

## 一、行业概况

### 市场规模

中国健身俱乐部市场约1500亿元年规模（2025年数据，含传统健身房、精品工作室、团课品牌三类）。全国注册健身门店约4万家，其中：
- 连锁品牌（威尔仕/一兆韦德/超级猩猩等）约6000家，占门店数15%，营收占40%
- 独立精品工作室（瑜伽/普拉提/CrossFit/搏击等）约2.8万家，占门店数70%，营收占45%
- 社区/小型健身房约6000家，占门店数15%，营收占15%

独立精品工作室是AI客服最精准的目标客户群——数量多、缺乏专职客服、痛点集中。

### 核心痛点

**痛点1：私教体验课转化率低**
精品工作室的获客主要靠体验课（99-199元），但体验课到店率只有35-45%，大量报名了体验课但不来。来了的，私教转化率约15-25%。从报名到成交，漏斗每一层都在流失。

**痛点2：客服响应慢导致流失**
工作室通常只有1-2个前台/客服，同时要接待到店会员、接电话、回微信。晚上8-10点是咨询高峰（下班后看小红书/大众点评后加微信咨询），但前台5点就下班了。晚上来的咨询第二天才回，意向客户流失率约40%。

**痛点3：续费率低**
健身房行业平均续费率约30-40%（年卡），精品工作室略高约45-55%。核心原因是会员到期前缺乏系统性的续费提醒和触达机制。依赖教练个人发微信提醒，覆盖率和话术质量参差不齐。

**痛点4：课程信息复杂**
精品工作室的课程类型多（私教/小团课/大团课/体验课/工作坊），每个课程有不同的适合人群、前置条件、时长、价格。用户咨询"我零基础能上你们的搏击课吗"这种问题，新前台根本答不清楚。

**痛点5：退费纠纷**
健身行业退费纠纷是消费者投诉高发区。退费政策表述不清、前台口头承诺与合同不一致、退费计算方式不透明——这些问题每天在发生。一个退费纠纷可能消耗店长3-5小时处理时间。

### 数字化程度：中

- **高**：连锁品牌已使用SaaS管理系统（三体云动/微健等），有完整的会员管理+约课+支付系统
- **中**：精品工作室约50%使用基础约课小程序，但客服端仍依赖微信人工回复
- **低**：社区/小型健身房基本靠微信+Excel管理

AI客服的落地空间在"中数字化"层——有约课系统但缺客服自动化的工作室。

## 二、AI落地场景（5个）

### 场景1：24小时智能咨询接待

**痛点描述**：工作室前台5点下班，晚上8-10点的咨询高峰无人回复。第二天回复时意向已降，转化率低。用户咨询的内容80%是重复性问题：你们有什么课、多少钱、零基础能上吗、怎么约体验课。

**AI解决方案**：RAG架构的AI客服接入企业微信。录入工作室的课程表、价目表、教练简介、适合人群说明。用户加企微后，AI自动识别意图（咨询课程/约体验课/问价格/问退费），从知识库检索回答。复杂问题（如"我有腰椎间盘突出能上你们的CrossFit课吗"）AI识别为需要教练判断，自动转给对应教练并附上用户的咨询上下文。

**预期效果**：咨询响应时间从6小时降到4秒以内，体验课到店率从35%提升到50-55%（快速回复提升信任感），咨询转化率提升约30%。

### 场景2：私教续费智能提醒

**痛点描述**：会员年卡/私教包到期前2周才开始提醒，且依赖教练个人发微信。教练忙的时候忘了发、话术不统一、有的会员没人提醒。续费率卡在45%。

**AI解决方案**：会员到期前30天/14天/7天/3天/1天五个节点，AI自动触发企微消息。每次触达内容不同：30天前推送"训练成果回顾"（基于该会员的到店频次/课程数据生成个性化报告），14天前推送"续费早鸟优惠"，7天前推送"教练推荐的下一步训练计划"，3天前转人工由教练语音跟进。AI生成每个会员的个性化消息内容，教练只需审核发送。

**预期效果**：续费提醒覆盖率从约60%（人工）提升到95%+，续费率从45%提升到55-60%。个性化触达的回复率比群发高3-5倍。

### 场景3：体验课智能筛选与预约

**痛点描述**：用户问"我应该上什么课"，前台不了解用户身体状况和目标，经常推荐不合适的课程。用户体验课后觉得不适合，流失。工作室白白了花99元体验课获客成本。

**AI解决方案**：AI客服在用户咨询阶段收集4个信息：训练目标（减脂/增肌/体态矫正/运动表现）、训练经验（零基础/有基础/资深）、身体状况（有无伤病史/腰椎/膝盖问题）、时间偏好。AI根据4个维度匹配最合适的体验课和教练。如果用户有腰椎问题，AI自动过滤掉CrossFit和深蹲类课程，推荐瑜伽或普拉提。

**预期效果**：体验课满意度从约60%提升到80%+，体验课转私教转化率从20%提升到30%+。降低不合适课程导致的退课纠纷。

### 场景4：退费政策透明化问答

**痛点描述**：退费纠纷频发，核心原因是前台口头承诺与合同条款不一致，退费计算方式用户不理解。一个退费纠纷消耗店长3-5小时，还可能被投诉到12315。

**AI解决方案**：AI客服在咨询阶段主动推送退费政策关键条款（未上课全额退/已上课按单节价扣/开卡30天后不退等），并要求用户确认知晓。退费计算器功能：用户输入"已上X节课"，AI根据合同自动计算应退金额，展示计算过程。减少信息不对称。

**预期效果**：退费纠纷减少约50%，退费处理时间从3-5小时降到30-60分钟（AI预计算+流程标准化）。

### 场景5：训练计划自动生成

**痛点描述**：私教课程间隔期间，会员在家不知道练什么，训练连续性差。教练给每个会员写家庭训练计划，每个会员花10-15分钟，20个会员就是3-5小时。

**AI解决方案**：AI根据会员的训练目标、当前进度、可用器材（家里有什么），自动生成个性化家庭训练计划。私教只需在App上审核确认。计划包含：动作名称、组数次数、替代动作（家里没有哑铃用矿泉水瓶替代）、注意事项（膝盖不适时替代动作）。

**预期效果**：教练每周节省3-5小时计划编写时间。会员训练连续性提升约40%（有计划指导 vs 无指导），间接提升续费意愿。

# 行业1：美容

## 一、行业概况

### 市场规模

中国美容行业（生活美容，不含医美）年市场规模约4500亿元，门店约35万家。细分：

- 身体SPA/按摩连锁约10万家，营收占25%
- 美甲美睫店约12万家，营收占15%
- 综合美容会所（面部+身体+美甲）约5万家，营收占30%

AI客服最佳目标客户群：综合美容会所和面部护理连锁——客单价高（200-2000元/次）、复购依赖强（月2-4次）、信息不对称严重。

### 核心痛点

**痛点1：晚上/午间咨询无人回复**
美容门店营业时间通常10:00-21:00，前台2-3人。晚上20-22点是咨询高峰（下班后看小红书/大众点评加微信），但前台19-20点就下班。第二天回消息时客户已约了竞品。流失率约40%。

**痛点2：项目信息极复杂**
综合美容所有30-80个项目——面部（清洁/补水/抗衰/祛斑/祛痘）、身体（SPA/经络/刮痧/艾灸）、美甲（法式/光疗/手绘/镶钻）。客户问"我T区出油但两颊干做什么项目"前台新员工答不上来，需要美容师评估。但AI不能做皮肤诊断（合规红线），只能做项目信息提供+预约面诊。

**痛点3：会员卡续费管理弱**
美容行业核心商业模式是预付卡（充值3000-20000元）。但续费提醒依赖前台/美容师手动发微信，覆盖率约50%，话术参差不齐。高价值客户（充值1万+）因续费提醒不到位流失，损失极大。

**痛点4：预约冲突频繁**
美容师各有排班，不同项目需要不同美容师+不同时长+不同房间。前台手动排期经常冲突（同一美容师同一时段被约2次、房间不够用）。改约/取消频繁，每天5-10起。

**痛点5：新客信任建立难**
美容行业口碑参差不齐（推销/隐形消费/效果承诺差），新客极度警惕。首次咨询时如果回答不专业/不一致/回复慢，直接流失。新客到店率约35%。

### 数字化程度：中

- 面部连锁：约60%使用美管SaaS/美丽修行等管理系统，有预约+会员+收银功能，但客服端仍依赖人工

## 二、AI落地场景（5个）

### 场景1：24小时智能咨询接待
**痛点**：晚上20-22点咨询高峰无人回复，流失率40%。

**预期效果**：晚上咨询回复率0%→85%。新客到店率35%→48%。月增约15%营收。

### 场景2：智能预约+排期管理
**痛点**：美容师排班+项目时长+房间资源手动管理，冲突频繁。
**AI方案**：DeepSeek API + RAG + 约课系统API。AI收到预约请求后查询美容师可用时段+项目所需时长+房间可用性→推荐3个时段→确认后写入系统。改约/取消自动同步。AI按项目匹配有资质的美容师（如祛斑需要特定资质）。

### 场景3：会员卡续费+复购提醒
**痛点**：预付卡续费提醒依赖人工，覆盖率50%，话术参差不齐。

### 场景4：项目智能推荐（不做诊断）
**痛点**：30-80个项目客户选不来，前台推荐不专业。
**AI方案**：DeepSeek API + RAG。AI走3步推荐：①了解需求（保湿/抗衰/放松/美甲）→②预算确认→③推荐3个适合项目+理由。推荐理由基于项目信息不基于皮肤诊断——"这款补水护理适合所有肤质，时长60分钟，体验价298元"。不承诺效果——"具体效果因人而异，建议到店面诊"。
**预期效果**：项目推荐准确率+35%。首次到店转化率+18%。退卡率10%→5%。

### 场景5：客户回访+满意度收集

**预期效果**：客户不满发现率+300%（从流失后才发现→24小时内发现）。好评引导发评率+50%。差评挽回率约35%。

### 核心痛点

**痛点1：白跑率高**
客户描述故障模糊——"空调不制冷"可能是遥控器问题/缺氟/主板故障。师傅带着工具跑了发现是小问题或没带对配件。每天5-8单白跑，每单成本100+。

**痛点2：报价不统一**
不同师傅报价不同，客户投诉。且电话报价后到店加项目，客户体验差。维修行业口碑差核心原因就是"不透明"。

**痛点3：紧急性判断不准**
水电维修中漏水/断电需1小时内到，普通维修可预约。但客服无法判断紧急程度——客户都说"很急"。真急的单被普通单挤掉。

**痛点4：调度效率低**
师傅定位+路由靠客服手动电话。谁离客户最近、谁有空、谁有对应资质，全靠人工记忆和电话确认。日效率低。

**痛点5：售后跟踪弱**
维修后没有回访。客户不满不知道，差评上了平台才发现。保修期内返修率高但无系统跟踪。

### 数字化程度：低

- 家电维修：约30%有工单系统，70%靠微信+电话
- 水电维修：约20%有调度系统，80%靠电话+微信群

# 行业5：心理咨询

## 一、行业概况

### 市场规模

中国心理咨询行业年市场规模约200亿元，含：
- 心理咨询中心/诊所约5000家，年营收约80亿
- 线上心理平台（壹心理/简单心理等）约15家，年营收约30亿
- EAP（员工心理援助计划）服务商约50家，年营收约40亿
- 心理热线/公益约50亿

AI客服最佳目标客户：心理咨询中心和线上平台——客户隐私要求高、咨询前置筛选需求强、合规要求严格。

### 核心痛点

**痛点1：首次咨询门槛高+信任建立难**
心理咨询有很强 stigma（病耻感）。客户首次咨询极度犹豫——"我是不是有病""心理咨询有用吗""咨询师会不会泄露隐私"。首次咨询回复慢/不专业/缺乏安全感直接流失。首次到店率约30%。

**痛点2：咨询师匹配困难**
不同咨询师专长不同（婚姻/亲子/职场/创伤/青少年）。客户不知道该选谁。前台不是心理咨询师，匹配不准=效果差=不再来。匹配率约45%。

**痛点3：危机干预缺失**
部分客户有自杀/自伤倾向。客服无法识别危机信号——客户说"活着没意思"时前台可能当普通咨询处理。这是重大安全风险。

**痛点4：预约管理复杂**
咨询师排班复杂——每个咨询师固定时段+不同咨询形式（面询/视频/电话）+不同时长（50分钟/90分钟）。手动排期经常冲突。

**痛点5：咨询后跟踪弱**
心理咨询需要多次。但咨询后没有系统跟踪——客户是否按时来下一次/状态变化/是否需要调整咨询师。流失率约60%（首次后不再来）。

### 数字化程度：低

- 咨询中心：约30%有预约系统，70%靠微信+电话
- 线上平台：自有系统较完善，但客服端仍人工
- EAP：约50%有工单系统

## 二、AI落地场景（5个）

### 场景1：首次咨询接待+信任建立（不做诊断）
**痛点**：首次咨询门槛高，回复慢/不专业直接流失。
**AI方案**：DeepSeek API + RAG。文档库包含咨询师资质/擅长领域/咨询流程/收费/隐私保护政策。AI用温和语气回答首次咨询——"心理咨询是专业的自我关怀，不是'有病'才需要。我们的咨询师均持有XX资质"。不做诊断——客户描述症状时AI回答"建议到店/线上与咨询师详谈，AI不做诊断"。首次咨询后发"首次体验价/免费15分钟初谈"邀请。
**预期效果**：首次到店率30%→42%。信任度+30%。

### 场景2：危机关键词检测+即时转人工
**痛点**：客服无法识别自杀/自伤信号，重大安全风险。
**AI方案**：DeepSeek API + RAG + 危机关键词检测。AI检测危机关键词（"不想活了""想死""结束一切""没有意义"等）→立即触发紧急流程——①推送值班咨询师②发送危机热线号码③AI转为温和陪伴模式"我理解你现在很痛苦，我们的咨询师XX马上联系你，24小时危机热线是XXXX"。AI不做危机干预——只做识别+转人工+发热线。
**预期效果**：危机识别率约85%。零延误转人工。安全风险大幅降低。

### 场景3：咨询师智能匹配
**痛点**：匹配率45%导致效果差、不来。
**AI方案**：DeepSeek API + RAG + 咨询师数据库。文档库包含每个咨询师的资质/擅长领域/咨询流派/性别/语言/可约时段。AI走3步匹配——①问题大类（婚姻/亲子/职场/创伤/青少年）→②偏好（性别/流派）→③推荐2-3位匹配咨询师+简介+预约链接。
**预期效果**：匹配率45%→72%。匹配率提升=效果好=复购+35%。

### 场景4：预约管理+咨询提醒
**痛点**：排期复杂+忘记来=空档。
**AI方案**：DeepSeek API + RAG + 预约系统API。AI处理预约/改约/取消。咨询前24小时/2小时发提醒。提醒附带咨询师介绍+咨询形式确认（面询地址/视频链接）。取消后自动填补等待名单。
**预期效果**：空档率12%→4%。咨询提醒打开率约80%。

### 场景5：咨询后跟踪+复购引导
**痛点**：首次后流失率60%。
**AI方案**：DeepSeek API + RAG + 咨询记录系统API。AI在咨询后48小时发温和跟踪——"上次咨询后感觉如何？有没有什么想继续讨论的？"不做诊断/不做效果评价。3级评分。低分推送咨询师调整方案。到期未续约AI发温和邀请——"您的咨询师XX本周有空档，是否需要继续？"不发促销话术（心理咨询不适合促销语气）。
**预期效果**：复购率40%→58%。跟踪打开率约65%。
